# Chat Bot Landing

## Descripción

Este es un proyecto e interfaz de un chat bot, el cual usa una API REST,
para responder preguntas al usuario, y mostrar una respuesta en pantalla,
el proyecto esta hecho con React, TypeScript, Tailwind CSS, Node.js,
usando Express para crear la API REST.

## Características

Este es un proyecto e interfaz de un chat bot que usa una API REST
para responder preguntas al usuario y mostrar una respuesta en
pantalla.

## Librerías y Dependencias

- React
- TypeScript
- Tailwind CSS
- Flowbite
- Axios
- React Router DOM
- React Helmet
- React Icons
- Node.js
- npm o pnpm

### En caso de usar pnpm, se recomienda instalarlo globalmente con el siguiente comando:

```bash
npm install -g pnpm
```

## Pasos para ejecutar el proyecto

1.**Clonar el repositorio**

```bash
git clone https://github.com/SASOPELANA/chat-bot-landing.git
```

2.**Navegar al directorio del proyecto**

```bash
cd chat-bot-landing
```

3.**Instalación de Dependencias**

```bash
pnpm install
```

4.**Iniciar el servidor de desarrollo**

```bash
pnpm run dev
```
